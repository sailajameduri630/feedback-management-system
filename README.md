# Feedback Management System

## About
A web-based feedback management application developed using Python, Flask, and SQLite. It allows users to submit feedback, provide ratings, and view submitted responses.

## Features
- Submit feedback through a web form
- Collect name, email, rating, and message
- Store feedback in an SQLite database
- Display submitted feedback in a tabular format

## Technologies Used
- Python
- Flask
- SQLite3
- HTML

## Project Structure
- `app.py` — Flask application and backend logic
- `feedback.db` — SQLite database for sample feedback
- `requirements.txt` — Python dependencies

## How to Run

1. Install Python.
2. Install the required package:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the application:

   ```bash
   python app.py
   ```

4. Open `http://127.0.0.1:5000` in your browser.
